# 用例文档的一些问题
1. 避免使用等、过长、不足等概况性词汇
2. 避免多别字
3. 描述用例时尽可能不要涉及页面等软件系统内部构造机制
4. 系统反馈是否过于简洁:用户进行评价
5. 是否持有不合理的类
